# Voice In (C# / .NET 10 / WPF)

**あなたの声を、あらゆる場所でスマートにテキスト化。**

Voice In は、Windows 上のあらゆるアプリケーション（エディタ、ブラウザ、Slack、Office 等）で動作する、AI 搭載の次世代音声入力ツールです。
Python 版から C# (.NET 10 / WPF) へ完全リプレイスされ、起動速度・メモリ効率・安定性が大幅に向上しました。

---

## ✨ 特徴

- **アクティブウィンドウへ自動入力 (Auto Paste)**: どのアプリで作業していても、キーを長押しして話すだけで、最適な文章が瞬時にカーソル位置へ自動入力されます。
- **選べる最新クラウド AI**:
  - **Google Gemini**: 高精度かつ自然な文章整形（デフォルト: `gemini-2.5-flash` / `gemini-2.0-flash`）
  - **Groq**: 超高速 Whisper (`whisper-large-v3`) + LLaMA 3.3 (`llama-3.3-70b-versatile`) による文章整形
- **コンテキスト認識プロンプト最適化**: 開発ツール（VSCode, ターミナルなど）、チャットツール（Slack, Teamsなど）、文書作成ツール（Word, Notionなど）を自動検知し、用途に合わせた最適なプロンプトを適用。
- **強力な文章整形**:
  - 不要な「えー」「あー」などのフィラーを完全除去
  - IT 用語や英単語の脱カタカナ化（「パイソン」→「Python」、「ギットハブ」→「GitHub」等）
  - 自然な句読点と敬語（です・ます調）の補正
- **柔軟な辞書機能**: 固有名詞や特殊な単語の置換ルールを設定画面から手軽に管理可能。
- **軽量・スマートな UI**:
  - デスクトップ上に常駐する丸型フローティングオーバーレイ（ドラッグ移動可能、状態に応じたパルスアニメーション）
  - タスクトレイ常駐メニューからワンクリックでプロバイダ切替・設定・履歴参照が可能。

## 🚀 はじめ方

### 1. 必要要件
- Windows 10 / 11 (64-bit)
- .NET 10 SDK または .NET 10 Desktop Runtime

### 2. 環境変数 (.env) の設定
プロジェクトルート（または実行ファイルと同じディレクトリ）に `.env` ファイルを配置します。

```ini
# .env 設定例
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
AI_PROVIDER=gemini
GEMINI_MODEL=gemini-2.5-flash
```

※ `.env.example` をコピーしてご利用ください。

### 3. ビルドと実行

```powershell
# ビルド
dotnet build

# 実行
dotnet run
```

## 🎙️ 使い方

1. 文字を入力したいアプリケーション（メモ帳、VSCode、Slackなど）をクリックしてフォーカスします。
2. **`Left Alt` キー（または設定画面で指定したキー）を押し続けます**。
3. オーバーレイが赤く点滅（🎙️）したら、マイクに向かって話します。
4. 話し終わったらキーを離します。
5. オーバーレイが黄色（⏳）で処理された後、緑色（✅）になり、整形されたテキストが自動的に貼り付けられます。

---

## ⚙️ 設定とカスタマイズ

タスクトレイのアイコン、またはオーバーレイを右クリックして **「設定」** を開くことで、以下をカスタマイズできます。

- **一般**:
  - AI プロバイダ切り替え (Gemini / Groq)
  - Gemini モデル指定
  - マイク入力デバイスの選択
  - 録音キーの変更 (Left Alt, Right Alt, Left Ctrl, Right Ctrl)
  - 最大録音時間 (秒)
  - 自動貼り付けの ON / OFF、貼り付け遅延 (ms)
- **プロンプト**:
  - 音声認識およびテキスト整形用システムプロンプトの編集
- **辞書**:
  - 「置換前 → 置換後」の単語ルールを登録
